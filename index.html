GraphForge 是一个完全离线的 OI 图论绘图工具。

输入格式

        
顶栏右侧的 EN / 中文 选择器可切换界面语言；选择会保存在本地。

        
由 DeepSeek 制作 · AI 生成。

        
边集：每行 u v 或 u v w，可带首行 n m。支持 ->、# 注释和全角符号。

        
邻接矩阵：每行 n 个数；首行可写 n。无向图会合并对称项，权值可写小数/负数；字符串编号可加 @ids A B C 标签行。

        
邻接表：u: v1 v2；带权可写 u: v1,w1 v2,w2 或 u: (v1,w1) …；也支持 n m 首行。

      

      

        
编辑与浮窗

        
点击节点/边编辑编号、显示名、颜色、尺寸、边权、方向与说明。说明文字可以直接单击编辑。拖动节点可移动；固定开关在节点属性中。

        
“字体与尺寸”可设置画布字体族（含等宽预设）、节点/边权/说明字号；勾选“节点按显示名自适应”后，长显示名会自动换行并放大节点。“边宽随边权自适应”会按数值边权调节粗细。

        
设置、随机、导出、帮助等窗口可拖动标题栏移动；点击窗口外可关闭。批处理面板同样可拖动，并可在外部点击或按 Esc 关闭。

        
双击空白处加点；工具栏“加边”依次点击两个节点；滚轮缩放，拖空白平移；F 适应画布。

      

      

        
布局与遍历

        
力导向使用带阻尼、速度上限与冷却的弹簧模型。稠密图（平均度达到统一设置阈值）默认改用圆形布局，通常比力导向更规则；仍可手动选择力导向。

        
点数超过性能阈值时自动进入性能模式：Barnes-Hut 斥力、空间网格碰撞、限制绘制频率，并简化超大图的说明/边权标签。仍是 SVG 渲染，不依赖 WebGL。

        
边说明优先放在边权左右/边侧空位，密集时分散到图的空白处，并用细引导线关联；完全图等极端稠密场景也会避免边说明与边权互相覆盖。

        
树形、基环树、二分图布局只在结构匹配时可用；BFS 可指定起点与方向。对树/森林点击 BFS 只标注访问序号，不改变现有结构；勾选“BFS 只标号，不改变布局”后，一般图也只标注 BFS 序号、保留节点位置，且改起点不再触发换根重排。未勾选时，在 BFS 序状态下更改起点可按“改 BFS 起点时换根并树形重排”开关换根、树形排版并重新标号；一般图按 BFS 层排版。对森林应用 BFS 后点击“树形”只更新 BFS 序号；换起点时仍用树形排版并标号。DFS 默认按遍历顺序蛇形排列；勾选“DFS 只标号，不改变布局”后仅标注 DFS 序号、不移动节点。树/森林的 DFS 顺序还可选“默认 / 重链剖分 / 长链剖分”。一般图的 BFS/DFS 可关闭“重排结构”；关闭后保留节点位置并标出遍历生成树（“标记 DFS/BFS 生成树”可关闭）。

      

      

        
Python API

        
“代码”页执行受限 Python 子集，运行在隔离 iframe 中。可读取标准输入、打印输出，或直接调用图 API 建图。生成后边集、邻接矩阵和邻接表会同步更新。默认脚本与批处理模板的注释、示例文案会随界面语言切换；用户修改过的代码不会被覆盖。

        

          
调用作用

          
print(...)输出/调试；输出可解释为边集、邻接表或矩阵

          
read_line() / read_all()读取一行 / 全部标准输入

          
add_edge(u, v, w?)直接加入一条边，可带边权

          
add_node(id)加入孤立节点

          
set_n(n) / set_directed(bool)预设顶点数 / 设置图类型

          
set_output_mode(mode)指定 print 输出格式：edges / adjlist / matrix

        

        
输出格式：未调用 set_output_mode 时自动识别 print 输出；也可在代码页右侧下拉框手动指定。建图成功后会同步三种文本表示。

        
语法：支持变量、if/elif/else、for、while、列表、range/map/enumerate/len/str/int/sum/min/max/sorted、字符串 .split()/.strip()/.lower()、列表 .append() 等。暂不支持 def、class、import、try、f-string、字典、多行表达式。

        
限制：代码 64 KB、stdin 1 MB、3 秒超时；range、列表、输出、节点和边均有上限。只运行你信任的脚本。

      

      

        
Python 批处理 API

        
“批量”面板对当前图执行脚本；未选中元素时，脚本可用全部节点/边。脚本只修改图模型，不自动改变布局；出错会回滚，3 秒超时。

        

          
对象 / 函数作用

          
nodes / edges全部节点 / 边

          
selected_nodes / selected_edges当前选中的节点 / 边

          
node(id) / edge(id 或 u,v)按编号查找节点 / 边

          
add_node / add_edge / remove_node / remove_edge增删节点或边

          
print(...)写入批处理输出面板

        

        
节点字段：id, label, note, fill, stroke, text_color, stroke_width, radius, x, y, fixed, degree, font_size

        
边字段：id, u, v, w/weight, note, color, width, dir, curve, label_color

        
示例：for node in selected_nodes: node.note = "core"；可直接运行批处理面板中的示例脚本。

      

      

        
随机生成

        
“随机”或空画布入口支持随机树、随机连通图、基环树、二分图、完全图；可设置点数、边数/环长、带权、边权范围、有向和固定种子。生成的图会替换当前画布，可用撤销恢复；完全图和稠密图自动使用圆形布局。

      

      

        
设置与导出

        
顶栏齿轮打开统一设置：同步开关、矩阵同步上限、稠密图圆形布局、BFS 换根、DFS 只标号、性能模式、字号/边宽/自动曲线，以及配色方案和逐项颜色。数值会限制在合理范围并自动保存。

        
导出支持 PNG（1×–4×、自动裁切、画布/纯白/透明背景）、SVG 矢量、动态 HTML（单文件、可拖拽节点、平移缩放、重置位置、再次下载 SVG）。导出不包含选中框和固定标记。

数据、保存与安全

        
工作区会自动保存到浏览器本地；也可以用“更多 → 导出项目 JSON”备份完整工程。边集、邻接矩阵、邻接表会在图形/代码/批处理变更后自动同步；非数字编号的矩阵使用 @ids 标签行；超过矩阵同步上限时矩阵视图保持不变。

        
顶栏项目按钮或“更多”菜单可导入/导出完整项目 JSON，也支持把 JSON 拖放到项目窗口。导入会校验 8 MB 大小、结构、节点/边数量、字段类型和遍历引用；不会执行项目中的代码，导入失败不会改动当前工作区，成功导入可撤销。

        
单文件分发版为 GraphForge.html，CSS/JS 全部内联，双击即可离线运行。

        
安全：输入有大小/行数/节点数/边数上限；标签会清理控制字符与非法颜色；Python 脚本在无同源权限的 iframe 中运行并限制 3 秒、代码/输出/图规模；动态 HTML 数据经过脚本转义，SVG 文本经过 XML 转义。
